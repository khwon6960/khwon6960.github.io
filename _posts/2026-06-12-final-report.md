# Final Project Review

## 무엇을 만들었나

이번 프로젝트에서는 한 학기 동안 제작한 기능들을 하나의 GitHub Pages 포트폴리오 사이트로 통합하였다. 사이트는 자기소개와 프로젝트를 소개하는 홈 화면을 중심으로 세 가지 텍스트 분석 도구를 제공한다.

첫 번째는 **Sherlok Holmes**의 **A Study in Scarlet**과 **The Hound of the Baskervilles**를 **비교하여 상위 단어 빈도를 시각화하는 비교 페이지**이고, 두 번째는 **Frankenstein**과 **Dracula**의 **단어 빈도를 분석하여 두 고딕 소설의 특징을 비교하는 페이지**이다. 세 번째는 **사용자가 직접 영어 텍스트를 입력하면 불용어를 제거한 뒤 상위 20개의 단어를 막대그래프로 보여 주는 Analyzer 페이지**이다. 또한 구현 과정을 기록한 블로그를 함께 구성하여 하나의 URL에서 모든 프로젝트를 확인할 수 있는 포트폴리오 사이트를 완성하였다.

## 어떤 문제를 겪고 어떻게 풀었나

프로젝트를 통합하는 과정에서 예상하지 못한 사소한 오타 때문에 여러 오류가 발생하였다. 먼저 JavaScript 코드에서 따옴표를 잘못 입력하여 스크립트가 정상적으로 실행되지 않았고, 브라우저 콘솔에서 오류 메시지를 확인한 뒤 잘못된 따옴표를 올바른 형태로 수정하여 해결하였다.

또한 정규표현식을 작성하는 과정에서 `/`와 `\`를 혼동한 실수도 있었다. 불용어 파일을 분리하기 위해 `split(/\s+/)`를 사용해야 했지만 잘못된 표현식을 사용하여 단어가 제대로 분리되지 않았고, 그 결과 차트에서 불용어가 제거되지 않은 채 상위 단어로 나타났다. 정규표현식을 다시 확인하여 올바르게 수정한 뒤에는 불용어가 정상적으로 제거되었고, 작품의 특징을 보여 주는 핵심 단어들만 차트에 표시되는 것을 확인할 수 있었다.


## 분석에서 발견한 것

이번 프로젝트에서는 여러 작품의 단어 빈도를 비교하고 사용자가 직접 입력한 텍스트를 분석하면서, 단어 빈도 분석만으로도 작품의 분위기와 서술 방식, 그리고 주제를 어느 정도 파악할 수 있다는 점이 가장 흥미로웠다. 자주 등장하는 단어는 단순히 많이 사용된 단어가 아니라 작품에서 반복적으로 강조되는 인물, 사건, 감정, 공간과 연결되어 있었고, 이를 통해 작품의 특징을 객관적인 데이터로 확인할 수 있었다.

이번 과제를 통해 텍스트 분석은 단순히 단어를 세는 작업이 아니라 문학 작품을 새로운 관점에서 이해하는 도구가 될 수 있다는 점을 경험하였다. 작품을 읽으며 느꼈던 인상을 데이터로 확인할 수 있었고, 서로 다른 장르와 작품을 비교하면서 인문학과 데이터 분석이 서로 보완적인 관계에 있다는 점이 인상적이었다.
